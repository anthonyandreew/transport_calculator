# Калькулятор рефинансирования

Статическая страница без зависимостей. Открыть `index.html` или запустить из корня репозитория `python3 -m http.server 8080` и перейти на `/refinancing/`.

Проверка расчётов: `node --test refinancing/calculator.test.cjs` из корня репозитория.

Текущие выплаты = сумма (платёж × оставшиеся месяцы). Новые расходы = новый платёж × срок + дополнительные расходы из своих денег. При вводе ставки используется аннуитетная формула с месячной ставкой = годовая / 12 / 100, без округления промежуточных результатов. Нулевая ставка поддерживается.

Переплата по текущим кредитам рассчитывается только при вводе всех остатков основного долга. При несовпадении суммы нового кредита с остатками долгов показывается предупреждение; разница выплат не объявляется чистой экономией. Сравнение предполагает полное погашение текущих кредитов новым. При незаданных остатках это допущение явно указано.

Ввод не сохраняется и не передаётся на сервер. Сторонних ресурсов и аналитики нет.
